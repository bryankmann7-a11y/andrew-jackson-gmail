# Jackson Letters Android

Gmail-style historical correspondence reader for Andrew Jackson, with bulk OCR import, source labels, and local offline storage.

**Important:** Starts with 14 example/adapted entries. They are not verified original quotations. The six-volume download is not pre-populated and has not yet been tested on a physical Android device. OCR results may need correction.

Build with GitHub Actions on push, then download **JacksonLetters-debug-APK** from the successful workflow's Artifacts section. Requires accepting installation of APKs from your browser/files app. The APK is a debug build, not a Google Play release.
